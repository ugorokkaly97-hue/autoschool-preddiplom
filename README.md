# Автошкола (преддипломный проект)

## Стек
PHP, Laravel, MySQL, Bootstrap

## Что умеет
- Запись на услуги автошколы
- Авторизация администратора
- CRUD услуг и инструкторов

## Как запустить (без Docker)
1. Склонировать репозиторий
2. Настроить .env
3. Выполнить `php artisan migrate`
4. Запустить `php artisan serve`
